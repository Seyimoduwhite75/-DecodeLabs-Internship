# Week 1: Data Cleaning Project (Excel)

## Overview

This project focuses on cleaning and preparing a raw dataset for analysis. Data cleaning is a crucial step in the analytics process, as the quality of insights depends heavily on the quality of the data.

## Objective

To transform a messy dataset into a structured, accurate, and analysis-ready format using Microsoft Excel.

## Tools Used

* Microsoft Excel

## Data Cleaning Process

The following steps were carried out:

* Handling missing values (removal or replacement where necessary)
* Removing duplicate records
* Correcting inconsistencies in text and data entries
* Standardizing data formats (dates, numbers, text)
* Using sorting and filtering to identify errors
* Applying conditional formatting to highlight anomalies

## Key Outcome

A clean and well-structured dataset ready for analysis and visualization.

##  Key Learnings

* Data cleaning is the foundation of any meaningful analysis
* Attention to detail is critical when working with datasets
* Excel is a powerful tool for data preprocessing

## Next Steps

Proceed to data analysis, where trends, patterns, and insights will be extracted from the cleaned dataset.







# Week 2: Exploratory Data Analysis (Trend, Outliers & Descriptive Statistics)

##  Overview

This project builds on the cleaned dataset from Week 1, focusing on analyzing the data to uncover trends, detect outliers, and summarize key statistics.

##  Objective

To explore the dataset and extract meaningful insights using descriptive statistics and trend analysis.

##  Tools Used

* Microsoft Excel

##  Analysis Performed

### 1. Descriptive Statistics

* Calculated mean, median, and count
* Summarized the overall distribution of the dataset

### 2. Trend Analysis

* Analyzed patterns over time or categories
* Identified increases, decreases, and consistent trends

### 3. Outlier Detection

* Identified unusual values that deviate significantly from the dataset
* Assessed their potential impact on analysis

### 4. Data Summarization

* Used  tables to group and summarize data
* Applied Excel functions for deeper insights

## Key Insights

* Identified patterns and trends within the dataset
* Highlighted anomalies that may affect decision-making
* Provided a clearer understanding of the data structure

##  Key Learnings

* Data analysis goes beyond numbers — it involves interpretation
* Outliers can significantly influence results and must be handled carefully
* Descriptive statistics provide a strong foundation for deeper analysis

##  Next Steps

Data visualization and storytelling to effectively communicate insights.
